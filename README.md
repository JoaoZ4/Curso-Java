# Java Complete Course

Repository created to store exercises, challenges and projects developed during the Java Complete: From Zero to Professional course by Cod3r.

## Topics Covered

- Java Fundamentals
- Algorithms and Data Structures
- Object-Oriented Programming
- Functional Programming (Lambdas and Streams)
- Exception Handling
- JavaFX
- Relational Databases (SQL)
- NoSQL Databases
- JPA / Hibernate
- Spring Boot

## Purpose

Track my progress and consolidate my knowledge in Java development through practical exercises and projects.
